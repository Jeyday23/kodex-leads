# Kodex Automated SEO Acquisition System

## Objective
Convert regulatory changes and search demand into authoritative pages, interactive assessments, scored leads and measurable revenue.

## Closed loop
Regulatory source -> topic graph -> quality-controlled page -> assessment -> scored lead -> CRM -> conversion -> SEO optimization.

## Core principles
1. Optimize for qualified leads, not raw traffic.
2. Publish from authoritative regulatory evidence.
3. Automate operations while retaining review for new legal interpretations.
4. Prevent thin content, duplication and keyword cannibalization.
5. Keep public SEO inventory on the main Kodex domain.

## Main modules
- Regulatory source monitor
- Search Console intelligence
- Topic and entity graph
- Content generation and refresh service
- Citation and claim ledger
- Quality gate
- Internal-link engine
- Dynamic Next.js publishing layer
- Lead and revenue attribution
- Admin approval and performance dashboard
